## Why

Basalt policies identify runtime effects with local scope and operation labels. Molten can identify those effects with canonical Kamacite semantic operation identities.

A local label does not bind the parameter schema, result schema, replay class, dependencies, or default behavior. A behavior change can therefore retain a familiar label.

Basalt needs one portable identity that follows an effect from reviewed policy into consumer authorization and runtime evidence.

## What Changes

- Pin one reviewed immutable Kamacite contract cohort for semantic operation descriptors and canonical Preserves values.
- Require exact Kamacite `effect-operation` identities in portable runtime-effect policy rules, requests, decisions, and receipts.
- Keep Basalt scopes and operation labels as consumer mapping metadata rather than canonical semantic identity.
- Add one canonical policy carrier that binds the generated policy, admitted descriptor cohort, adapter identity, and compatibility JSON.
- Permit substitution only through an exact directional Kamacite compatibility artifact admitted for live host execution.
- Add frozen Animus, Lattice, and Molten mappings with positive and negative drift cases.

## Dependencies

- Kamacite owns semantic operation descriptors, compatibility artifacts, canonical Preserves values, and adapter receipts.
- Basalt retains Nickel policy meaning, UCAN composition, authorization decisions, and metadata-only receipts.
- Consumers retain request parsing, currentness, native enforcement, effect execution, and runtime observations.

## Non-Goals

- Making Kamacite an authorization system.
- Replacing Basalt policy, UCAN, Cap Root, Bounded Exec, or consumer effect adapters.
- Claiming that equal identities prove correct behavior or successful execution.
- Requiring Kamacite for Basalt policy that never crosses a declared interchange boundary.

## Impact

- **Policy**: runtime-effect rules gain exact semantic operation identities and a canonical portable carrier.
- **Core**: pure admission and decision logic receives a Basalt-owned nominal semantic operation reference.
- **Adapters**: a narrow boundary validates Kamacite descriptors and compatibility artifacts before core use.
- **Consumers**: frozen mappings prove exact identity retention without adding runtime dependencies.
- **Testing**: name-equal identity drift, wrong domains, stale descriptors, reverse compatibility, and overclaim cases fail closed.
